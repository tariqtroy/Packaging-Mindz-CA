# Packaging Mindz CA - One Page Landing Page

Static site for GitHub Pages. Upload everything in this folder to the repository root:
`index.html`, `style.css`, `robots.txt`, `sitemap.xml`, and the `images/` folder.

Before publishing, replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `index.html`, `robots.txt`, and `sitemap.xml` with your real GitHub Pages URL.

All images are local files in `images/` (no remote images). Swap any illustration for a real photo by keeping the same filename or updating the `src` in `index.html`.
